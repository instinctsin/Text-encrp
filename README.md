# Text-encrp

웹 브라우저 안에서 최신 Web Crypto API를 사용해 텍스트를 암호화/복호화할 수 있는 실험용 도구입니다. 별도 서버 없이 정적 페이지를 블로그 글에 삽입하거나 링크로 공유해 손쉽게 사용할 수 있습니다.

## 주요 기능

- **세 가지 암호화 버전 제공**
  - V1: AES-GCM 256bit + PBKDF2(250,000회)
  - V2: AES-CBC 256bit + PBKDF2(200,000회)
  - V3: AES-CTR 256bit + PBKDF2(150,000회)
- 암호화 시 결과(JSON)를 복사해 공유 가능
- 복호화 시에는 세 가지 방식을 모두 시도하여 각각의 결과를 별도로 출력
- Web Crypto API 기반으로 모든 처리가 브라우저 내부에서 이루어져 텍스트가 서버로 전송되지 않음

## 사용 방법

1. `index.html` 파일을 브라우저에서 열거나 정적 웹 서버(예: `python -m http.server`)로 실행합니다.
2. **텍스트 암호화**
   - 평문과 비밀번호, 사용할 암호화 방식을 선택합니다.
   - "텍스트 암호화" 버튼을 누르면 JSON 형태의 암호화 결과가 생성됩니다.
   - "복사" 버튼으로 결과를 클립보드에 복사해 블로그나 메신저 등에 붙여넣을 수 있습니다.
3. **텍스트 복호화**
   - 암호화 단계에서 얻은 JSON 문자열을 붙여넣고 동일한 비밀번호를 입력합니다.
   - "모든 방식으로 복호화" 버튼을 누르면 V1/V2/V3 세 가지 방식 각각에 대한 결과가 카드 형태로 표시됩니다.
   - 비밀번호나 암호화 방식이 맞지 않으면 해당 카드에 실패 메시지가 나타납니다.

## 배포

정적 호스팅이 가능한 어떤 플랫폼(블로그, GitHub Pages 등)에서도 `index.html`, `styles.css`, `app.js` 세 파일을 업로드하면 바로 실행할 수 있습니다.
